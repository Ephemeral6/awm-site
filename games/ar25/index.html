Replay

The certified run that cleared every level, one action at a time.

Press Play or step to load the run. Keys, while the player is on screen: ← → step, Space play / pause. A click is circled; cells that changed are outlined.

How it plays

The screen has black objects, light-blue separator bands (whole rows or whole columns) and yellow target blocks; the dark grey ones are the mirror images of the objects. First click once to select an object or a separator band, then use the arrow keys to push it one cell. The separator bands are mirrors: each object has an image with respect to each band, and when an object is pushed the image moves along with it, when a band is pushed the mirror moves one cell and the image moves two cells; when one horizontal and one vertical band cross, there is also one more image, rotated half a turn about the intersection. The level is cleared when every yellow target block is covered by an object or by its image. A band drawn solid cannot be pushed; pushing it off the board, or against another object, cannot be pushed either; images that land off the board are not drawn. There is also a key that makes the selected one step back one step.

Model

The final model: 6 object types and 8 rules. Each rule is a Python check against every recorded step; 5 of them are translated into Lean (the paper's per-game table). Code under a rule is the file of the same name in the agent's Lean project.

namespace Game

inductive Dir
  | up | down | left | right
deriving DecidableEq, BEq, Repr

def stepCell : Dir → Cell → Option Cell
  | .up, x    => if rowOf x ≥ 1 then some (x - STRIDE) else none
  | .down, x  => if rowOf x + 1 < NB then some (x + STRIDE) else none
  | .left, x  => if colOf x ≥ 1 then some (x - 1) else none
  | .right, x => if colOf x + 1 < NB then some (x + 1) else none

def stepCells (d : Dir) : List Cell → Option (List Cell)
  | [] => some []
  | x :: xs => match stepCell d x, stepCells d xs with
    | some y, some ys => some (y :: ys)
    | _, _ => none

def stepLine : Dir → Line → Option Line
  | .up, l    => if l.horiz ∧ l.k ≥ 1 then some { l with k := l.k - 1 } else none
  | .down, l  => if l.horiz ∧ l.k + 1 < NB then some { l with k := l.k + 1 } else none
  | .left, l  => if !l.horiz ∧ l.k ≥ 1 then some { l with k := l.k - 1 } else none
  | .right, l => if !l.horiz ∧ l.k + 1 < NB then some { l with k := l.k + 1 } else none

def pushBand (b : Board) (w : World) (i : Nat) (d : Dir) : Option World :=
  match w.bands[i]? with
  | none => none
  | some x =>
    if b.frozen.contains x.line then none else
    match stepLine d x.line with
    | none => none
    | some l' =>
      if w.bands.any (fun y => y.line == l') then none
      else some { w with bands := w.bands.set i { line := l' } }

def pushPiece (w : World) (j : Nat) (d : Dir) : Option World :=
  match w.pieces[j]? with
  | none => none
  | some p =>
    match stepCells d p.cells with
    | none => none
    | some cs =>
      let others := minusMask w.body p.mask
      if maskOf cs &&& others != 0 then none
      else some { w with pieces := w.pieces.set j { cells := cs } }

def push (b : Board) (w : World) (d : Dir) : Option World :=
  if w.sel < w.bands.length then pushBand b w w.sel d
  else pushPiece w (w.sel - w.bands.length) d

end Game

namespace Game

def PX : Nat := 3

def firstIx {α} (p : α → Bool) : List α → Nat → Option Nat
  | [], _ => none
  | a :: as, i => if p a then some i else firstIx p as (i + 1)

def clickedIx (b : Board) (w : World) (x y : Nat) : Option Nat :=
  if y / PX ≥ NB ∨ x / PX ≥ NB then none else
  match firstIx (fun p => memMask p.mask (cellAt (y / PX) (x / PX))) w.pieces 0 with
  | some j => some (w.bands.length + j)
  | none =>
    match ghostMask w with
    | none => none
    | some g =>
      if memMask g (cellAt (y / PX) (x / PX)) then none else
      match w.bands.filter (fun z => memMask (bandMask b z) (cellAt (y / PX) (x / PX))) with
      | [z] => firstIx (fun u => u == z) w.bands 0
      | _ => none

def click (b : Board) (w : World) (x y : Nat) : Option World :=
  match clickedIx b w x y with
  | some i => some { w with sel := i }
  | none => none

end Game

theorem Game.click_is_free (b : Board) (w w' : World) (x y : Nat)
    (h : step b w (.click x y) = .ok w') :
    w'.used = w.used ∧ w'.bands = w.bands ∧ w'.pieces = w.pieces := by
  simp only [step] at h
  cases hc : click b w x y with
  | none => simp [hc] at h
  | some w'' =>
    simp only [hc, Res.ok.injEq] at h
    subst h
    simp only [click] at hc
    cases hi : clickedIx b w x y with
    | none => simp [hi] at hc
    | some i =>
      simp only [hi, Option.some.injEq] at hc
      subst hc
      exact ⟨rfl, rfl, rfl⟩

What a pass establishes

consistent: for every recorded transition, as read by the agent's parser and with duplicates removed, every rule whose condition holds also has its effect hold. faithful: the certified run, recomputed step by step from the first screen of each level, matches the record and ends in a win. Axioms used: propext, all among Lean's standard ones.

What it does not establish: that the parser reads the screens correctly (that step runs in Python, outside Lean), or that a rule whose condition never occurs in the record is right. The Python file that produced the readings inside the model file is in the archive at meta/repair-20260928/lib/ar25-20260920/_lib.py.
