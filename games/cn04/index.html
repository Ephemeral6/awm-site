Explained by

Press Play or step to load the run. Keys, while the player is on screen: ← → step, Space play / pause. A click is circled; cells that changed are outlined.

How it plays

There are several pieces of different shapes on the field, each with a red plug. Only the selected piece can be operated at a time: a direction key translates it by one cell, and the function key rotates it clockwise by a right angle; if it is a pen, the function key lengthens it by one segment or shortens it by one segment. Click another piece and the selection switches to it; click the already selected piece again and the selection is cancelled. Pieces can walk over each other and are not blocked. When two plugs land on the same cell, that cell turns grey to indicate it is welded; after they move apart each is restored. After a step, if every plug on the field overlaps another plug in the same cell, the level is cleared. Some levels paint the whole unselected piece dark and hide its plug, visible only when selected. The top bar at the very top is spent down with the steps.

Model

The final model: 4 object types and 9 rules. Each rule is a Python check against every recorded step; 8 of them are translated into Lean (the paper's per-game table). Code under a rule is the file of the same name in the agent's Lean project.

Object types

  • Ground colour groundThe background colour of this level, different in each level.
  • Top bar spentThe progress bar at the very top; how many cells are already spent.
  • Selected piece litIts solid cells, plug cells, pen tip and colour; the keys operate this piece.
  • Other pieces restEvery non-ground cell outside the selected piece, with its shown colour.

def shiftCell (d : Int × Int) (p : Cell) : Cell := (p.1 + d.1, p.2 + d.2)

def Shape.shift (d : Int × Int) (sh : Shape) : Shape :=
  ⟨sh.solid.map (shiftCell d), sh.plugs.map (shiftCell d), sh.head.map (shiftCell d)⟩

def Piece.shift (d : Int × Int) (p : Piece) : Piece := { p with stages := p.stages.map (Shape.shift d) }

def mapAt {α : Type} (f : α → α) : Nat → List α → List α
  | _, [] => []
  | 0, x :: xs => f x :: xs
  | n + 1, x :: xs => x :: mapAt f n xs

def move (d : Int × Int) (s : World) : World :=
  match s.sel with
  | none => s
  | some i => { s with pieces := mapAt (Piece.shift d) i s.pieces }

def minOf (xs : List Int) : Int := xs.foldl min (xs.headD 0)
def maxOf (xs : List Int) : Int := xs.foldl max (xs.headD 0)

def Shape.turn (sh : Shape) : Shape :=
  let all := sh.solid ++ sh.plugs
  let r0 := minOf (all.map Prod.fst)
  let c0 := minOf (all.map Prod.snd)
  let h := maxOf (all.map Prod.fst) - r0 + 1
  let f : Cell → Cell := fun p => (r0 + (p.2 - c0), c0 + (h - 1 - (p.1 - r0)))
  ⟨sh.solid.map f, sh.plugs.map f, sh.head.map f⟩

def Piece.turn (p : Piece) : Piece := { p with stages := p.stages.map Shape.turn }

def turn (s : World) (i : Nat) : World := { s with pieces := mapAt Piece.turn i s.pieces }

end Game

def _same_outside(w, nw, cells):
    a = {(r, c): v for (r, c, v) in w.rest if (r, c) not in cells}
    b = {(r, c): v for (r, c, v) in nw.rest if (r, c) not in cells}
    if w.lit is not None:
        for p in w.lit.cells() - cells:
            a[p] = w.lit.shown(*p)
    if nw.lit is not None:
        for p in nw.lit.cells() - cells:
            b[p] = nw.lit.shown(*p)
    return a == b

def judge_w(w, a, nw, ctx):
    if nw.ground != w.ground or look_of(nw) != look_of(w):
        return False
    p = cell_of(a)
    k = what(w, p)
    if k == "ground":
        return _same_outside(w, nw, frozenset())
    old = w.lit.cells() if w.lit is not None else frozenset()
    if k == "lit":
        return (nw.lit is None and all(nw.color_at(*q) == SLEEP for q in old)
                and _same_outside(w, nw, old))
    comp = component(w, p, through=old if look_of(w) == "sleep" else frozenset())
    if nw.lit is None or p not in nw.lit.cells():
        return False
    if look_of(w) == "sleep":
        if not nw.lit.cells() <= comp | old:
            return False
        for q in old - nw.lit.cells():
            if nw.color_at(*q) != SLEEP:
                return False
        return _same_outside(w, nw, comp | old)
    if nw.lit.solid != comp:
        return False
    was = w.lit.solid if w.lit is not None else frozenset()
    shown = {nw.color_at(*q) for q in was}
    if len(shown) != 1 or shown & {MASK, MARK, WELD, SLEEP, w.ground}:
        return False
    return _same_outside(w, nw, comp | was)

namespace Game

def clickCell (x y : Nat) : Option Cell :=
  if x < 2 || y < 2 then none else some (((y - 2) / 3 : Nat), ((x - 2) / 3 : Nat))

def Shape.covers (sh : Shape) (p : Cell) : Bool :=
  sh.solid.contains p || sh.plugs.contains p || sh.head == some p

def hits (s : World) (p : Cell) : List Nat :=
  (List.range s.pieces.length).filter (fun i => (s.piece i).cur.covers p)

def pick (s : World) (x y : Nat) : World :=
  match clickCell x y with
  | none => s
  | some p =>
    match s.sel with
    | some i =>
      if (hits s p).contains i then { s with sel := none }
      else (match hits s p with
            | [] => s
            | j :: _ => { s with sel := some j })
    | none =>
      (match hits s p with
       | [] => s
       | j :: _ => { s with sel := some j })

end Game

What a pass establishes

consistent: for every recorded transition, as read by the agent's parser and with duplicates removed, every rule whose condition holds also has its effect hold. faithful: the certified run, recomputed step by step from the first screen of each level, matches the record and ends in a win. Axioms used: propext, all among Lean's standard ones.

What it does not establish: that the parser reads the screens correctly (that step runs in Python, outside Lean), or that a rule whose condition never occurs in the record is right.
