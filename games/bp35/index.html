bp35

Move the player sideways, click to change terrain and gravity, and reach the pink cross to clear the level.

9 levels · 11 rules · all levels replayed in Lean

How it playsReplayModelProofFiles

How it plays

Each level is a vertical shaft taller than the screen, and the camera follows the player. The player is one cell in the liquid, and its yellow nose points the way it faces. The left and right keys move it one cell sideways; vertically it cannot move by itself — after every step and every click it is carried all the way along the direction of gravity by the liquid. What can be clicked changes the terrain: the red switch flips gravity (floating up becomes sinking), the green rounded block turns into liquid when clicked, an orange block and an empty slot with a small cross swap when clicked, and when a purple foam block is clicked the liquid around it also turns into foam. The level is cleared when the player walks sideways into, or is carried into, the pink cross cell. When floating up the cross is below, and cannot be reached without flipping gravity. The undo key can step back one step at a time, and the step counter in the bottom row still grows.

Replay

The certified run that cleared every level, one action at a time.

Keys: ← → step, Space play / pause. A click is circled; cells that changed are outlined.

Model

The final model: 3 object types and 11 rules. Each rule is a Python check against every recorded step; most are also Lean definitions.

Object types

  • Cells cellsVisible grid: walls, liquid, rounded blocks, empty slots, crosses and the player's cell.
  • Facing facingWhether the player's yellow nose points left or right.
  • Step counter hudThe bottom row, which records how many steps this level has taken.

inductive Drift where
  | stop (r : Int)
  | goal
  | unknown
  deriving DecidableEq, Repr

def driftFrom (m : Map) (c d : Int) : Nat → Int → Drift
  | 0, _ => .unknown
  | n + 1, r =>
    match m.get (r + d) c with
    | .goal => .goal
    | .unk => .unknown
    | t => if t.passable = true then driftFrom m c d n (r + d) else .stop r

def cellOk (model seen : Tile) : Bool := model == .unk || model == seen

def rowOk : List Tile → List Tile → Bool
  | [], [] => true
  | a :: as, b :: bs => cellOk a b && rowOk as bs
  | _, _ => false

def rowsOk : List (List Tile) → List (List Tile) → Bool
  | [], [] => true
  | a :: as, b :: bs => rowOk a b && rowsOk as bs
  | _, _ => false

def seenOk (model seen : World) : Bool :=
  rowsOk model.cells seen.cells && model.facing == seen.facing && model.hud == seen.hud

def agrees (prev : World) (a : Act) (next : World) (won : Bool) : Option Bool :=
  match step (ofWorld prev) a with
  | .won => some won
  | .na => none
  | .ok s => some (!won && seenOk (view s) next)

  | _, s, [], last => step s last == .won

      | _ => false
