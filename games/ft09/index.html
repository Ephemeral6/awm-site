How it plays

On the screen there are several nine-grids: the outer ring consists of tiles that can be clicked (some positions are empty, or are the centre of another nine-grid), and the block in the exact centre draws the question pattern of this grid. In some levels there is a legend at the top right, listing from top to bottom this level's palette. Click a tile and its colour changes along the palette to the next one, wrapping back to the first at the end; in the first level only the nine-grid circled by the square frame can be clicked, and the others are examples. If a tile has a mark on its side, the neighbouring block that the mark points to also changes colour by one step, passed on for this step only. Adjacent nine-grids may share tiles of the outer ring. When every nine-grid is matched to its question pattern, the level is cleared: the positions lit in the pattern are this grid's lit colour, and the other positions are another single colour. The bottom row is a counter bar, used up as the steps in this level go by.

Model

The final model: 6 object types and 7 rules. Each rule is a Python check against every recorded step; most are also Lean definitions.

Object types

  • Palette paletteThis level's colours and their order, listed top to bottom in the top-right legend.
  • Tiles tilesThe position of each clickable tile and whether each of its sides has a mark.
  • Nine-grids gridsEach nine-grid's centre, its lit colour, and the small pattern drawn at its centre.
  • Colours colorsThe current colour of each tile.
  • Counter bar bar_usedThe bottom row of the screen: how many cells this level has used.
  • Backdrop backdropThe rest of the screen outside tiles, nine-grid centres and the counter bar.

def advance (pal : List Nat) (c : Nat) : Nat :=
  match pal.idxOf? c with
  | some i => pal.getD ((i + 1) % pal.length) c
  | none   => c

def World.gridDone (w : World) (g : Grid) : Bool :=
  let cols := g.ring.map (fun p => (p.1.bind w.colorAt, p.2))
  let onsOk := cols.all (fun p => p.2 != .on || p.1 == some g.lit)
  let offs := cols.filter (fun p => p.2 == .off)
  let offCols := offs.filterMap (fun p => p.1)
  onsOk && offCols.length == offs.length
    && offCols.all (fun c => c != g.lit)
    && offCols.all (fun c => c == offCols.headD 0)

def World.isGoal (w : World) : Bool :=
  w.board.grids.all w.gridDone
