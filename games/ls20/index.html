Walk a block to doors that match your key; walking into the last door clears the level.

7 levels · 21 rules · all levels replayed in Lean

How it playsReplayModelProofFiles

How it plays

The player is a block, and the direction keys make it walk one cell. Each door has a pattern drawn on it, and the key in the player's hand is in the bottom-left corner. Only when the key's shape and colour are both the same as the door's can it walk into the door; walking into the last door clears the level. The key is changed by stepping on things on the ground: a white cross switch makes it turn a right angle clockwise, a white switch of another shape changes it to the next shape, and a coloured small block changes it to the next colour. Every step taken deducts energy, and when the energy bar at the bottom is used up and one steps again, a life is lost (the red block in the bottom-right corner) and the level restarts; a yellow small square is a supply, and walking into it refills the energy. The light-coloured thin strips beside the walls are spring lines, and stopping beside them one gets pushed sliding all the way. On some levels the switches walk back and forth along a fixed path, one cell for each step the player moves; one level has fog, where only a ring around the player can be seen.

Replay

The certified run that cleared every level, one action at a time. Beside each step: the rules of the model that explain it.

Explained by

Keys: ← → step, Space play / pause. A click is circled; cells that changed are outlined.

Model

The final model: 12 object types and 21 rules. Each rule is a Python check against every recorded step; most are also Lean definitions.

Object types

  • Player meThe cell where the player block stands now.
  • Floor floorWhich cells the player can walk on.
  • Fog hiddenCells hidden by fog in this frame; empty on levels without fog.
  • Spring lines linesLight thin strips on cell edges, and which way they push the player.
  • Doors goalsWhere each door is and what key it needs, in shape and colour.
  • Cross switches rotatorsWhite crosses; stepping on one turns the key a right angle clockwise.
  • Non-cross switches shapersWhite switches of other shapes; stepping on one changes the key to the next shape.
  • Colour blocks paintersColoured small blocks; stepping on one changes the key to the next colour.
  • Supplies refillsYellow small squares; walking in refills the energy, and the supply then disappears.
  • Key keyThe pattern in the bottom-left corner, with a shape and a colour.
  • Energy energyHow much is left in the energy bar at the bottom.
  • Lives livesThe red blocks in the bottom-right corner: how many lives remain.

inductive Land where
  | wall
  | locked
  | opened (c : Cell)
  | step (c : Cell)
  | slide (c : Cell)
deriving Repr

def landingAt (b : Board) (w : World) (t : Cell) : Land :=
  if isWall b t then .wall
  else if isLocked w t then .locked
  else if (goalAt t w.goals).isSome then .opened t
  else match slideFrom b w t with
    | some c => .slide c
    | none   => .step t

def landing (b : Board) (w : World) (d : Delta) : Land :=
  match w.me.shift d with
  | none   => .wall
  | some t => landingAt b w t

def slideRun (b : Board) (goals : List Goal) (d : Delta) : Nat → Cell → Cell
  | 0, c     => c
  | n + 1, c =>
    match c.shift d with
    | none    => c
    | some nx =>
      if memC nx b.floor && (goalAt nx goals).isNone then slideRun b goals d n nx else c

def slideFrom (b : Board) (w : World) (t : Cell) : Option Cell :=
  match pushAt t b.lines with
  | none   => none
  | some p => some (slideRun b w.goals p 12 t)

def forms : List Nat := [466, 493, 174, 410, 359, 371]

def rotN : Nat → Nat → Nat
  | 0, s     => s
  | n + 1, s => rotN n (rotCw s)

def findForm (s : Nat) : List Nat → Nat → Option (Nat × Nat)
  | [], _      => none
  | f :: fs, i =>
    if rotN 0 f == s then some (i, 0)
    else if rotN 1 f == s then some (i, 1)
    else if rotN 2 f == s then some (i, 2)
    else if rotN 3 f == s then some (i, 3)
    else findForm s fs (i + 1)

def nextForm (s : Nat) : Option Nat :=
  match findForm s forms 0 with
  | none        => none
  | some (i, r) => some (rotN r (forms.getD ((i + 1) % 6) 0))

def reshapeKey (k : Key) : Option Key :=
  (nextForm k.shape).map (fun s => { k with shape := s })

def _ok(p, w, nw) -> bool:
    K, NK = getattr(w, p.kind), getattr(nw, p.kind)
    seen = {c for c in K if p.along(c) is not None}
    now = {c for c in NK if p.along(c) is not None}
    dark_prev = {w.me} | set(w.hidden)
    dark_next = {nw.me} | set(nw.hidden)
    if w.me == nw.me:
        return {c for c in seen if c not in dark_next} == {c for c in now if c not in dark_prev}
    for q in seen:
        if not any(q2 in now or q2 in dark_next for q2 in patrol_next(p, q)):
            return False
    for q2 in now:
        if not any(q in seen or q in dark_prev for q in patrol_next(p, q2)):
            return False
    return True
