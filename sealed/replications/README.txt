AWM sealed-level replication records

GitHub Pages serves the repository root of main. Merging this directory into
main publishes it at /awm-site/sealed/replications/ on the Pages site.

For a local check, run python -m http.server 8766 --bind 127.0.0.1 from the
repository root and open http://127.0.0.1:8766/sealed/replications/.

The overview gives the selection rule and separates initial reports,
follow-up reports, and the operator's conversion to the reference budget
convention. The records viewer shows answers, final interviews, available
follow-ups and Lean files. See records/EXPORT-NOTES.txt for what the six
downloadable public-evidence ZIPs contain.

The ZIPs are the distribution copies of the full public-evidence packages.
The separate viewer data contains only the fields and Lean files needed for
browsing. Gameplay and other model files are available inside the ZIPs.

The sc25 reference image comes from the earlier sealed-level archive.
