AWM replication page — additive-only preview

Only this new directory is supplied. No existing website file has been edited.
The ZIP places these files under sealed/replications/. Existing index, styles,
scripts, historical data and routes are left untouched. Visit the new URL
directly; adding a link to an existing page is outside this preview's scope.

Serve locally with Python:
  python -m http.server 8766 --bind 127.0.0.1
Then open http://127.0.0.1:8766/ in a browser.
Use HTTP rather than file:// so the audit JSON can load.

The preview includes six selected cases, their proof scopes, the independent
engine-transfer repair, and a revision-pinned source review of the 25-game
retrofit. It is not a publication or a claim of 25 independent final passes.

Open records/ for the attempt-by-attempt viewer. Each run has eight initial
attempts, a final interview, available same-case follow-ups, endpoint model
files and a complete public-evidence ZIP. Download scope and exclusions are
documented in records/EXPORT-NOTES.txt. Source protocol metadata is retained
without separating the six cases into different navigation groups.

Read review.txt for evidence, limitations and outstanding acceptance work.
